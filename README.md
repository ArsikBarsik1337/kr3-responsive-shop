## Исправления доступности

- Для ссылок в шапке добавлен белый видимый фокус, так как синяя обводка не различалась на фоновом изображении.
- Повышена контрастность: цвет бейджа «Новинка» затемнён (`#137a29`), на фон шапки добавлено затемнение.
- В `index.html` удалён дублирующийся `id="success-message"`.
- На `product.html` кнопка «Заказать» теперь открывает модальное окно (исправлен селектор в `main.js`).
- Атрибут `aria-invalid` снимается с поля сразу после исправления ошибки.
